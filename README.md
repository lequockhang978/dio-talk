# ⚓ Dio Talk • MC1 VERSION

**Hệ Thống Luyện Phát Âm & Đàm Thoại Tiếng Anh Hàng Hải Chuẩn Quốc Tế (STCW 78/2010 - IMO SMCP)**

- **Tác giả**: LÊ QUỐC KHANG (MC1 VERSION)
- **Chuẩn kỹ năng**: STCW A-II/1 & IMO SMCP
- **Công nghệ**: React 19 + TypeScript + Vite + Capacitor 8 (Android) + Firebase Cloud

---

## 🚀 Tính năng nổi bật

1. **Kho từ vựng hàng hải chuyên sâu**:
   - 10,000+ thuật ngữ hàng hải chuyên ngành theo từng phân cấp (Sĩ quan boong, Máy tàu, Thuyền trưởng, Hoa tiêu).
   - Tích hợp phát âm chuẩn IPA và ví dụ ngữ cảnh thực địa.

2. **Đàm thoại vô tuyến VHF & Tình huống khẩn cấp (Emergency / SAR)**:
   - Các kịch bản trực canh VHF, cứu nạn cứu hộ (Mayday, Pan Pan, Securite), điều động tàu tại cảng và luồng hẹp.

3. **15 Minigame Tương Tác Hàng Hải**:
   - Trắc nghiệm phản xạ, giải mã SMCP, mô phỏng buồng lái, xử lý tình huống khẩn cấp.
   - Thuật toán chống lặp câu hỏi 100%.

4. **Trợ lý AI Đàm thoại Hàng Hải**:
   - Tích hợp 20 mô hình AI tương thích chuẩn OpenAI SDK.
   - Đánh giá phát âm, chấm điểm độ chính xác ngữ pháp và phản xạ STCW.

5. **Cập nhật trực tuyến Online (OTA Update)**:
   - Tự động kiểm tra phiên bản mới qua GitHub Releases & Firebase Firestore.
   - Thông báo và tải cài đặt trực tiếp file APK.

## 📦 Cài đặt & Phát triển

```bash

# Khởi chạy môi trường Dev
npm run dev
```
